# Glintmotion Effects

A library of motion effects for [Glintmotion](https://github.com/Soflutionltd) and any
[HyperFrames](https://github.com/heygen-com/hyperframes) project: shader transitions today,
text, 3D and background effects next. Every effect is checked by a real render before it
is accepted.

The catalog uses the HyperFrames registry format, so the same `add` command installs from
it. Glintmotion reads it next to the HyperFrames catalog.

## What is inside

| Folder | Content |
| --- | --- |
| `components/` | Installable items, generated by `scripts/build-registry.mjs` |
| `effects/` | Hand-written effects built on the GSAP plugins HyperFrames does not use |
| `transitions/gl/` | 123 transitions from [GL Transitions](https://gl-transitions.com), converted for HyperShader |
| `vendor/hyper-shader/` | The HyperShader runtime with `registerShader`, built from the Glintmotion fork |
| `scripts/` | Import, build and gallery scripts |

## Use a transition

Install `gl-cube` (or `gl-transitions` for all of them). It brings
`vendor/glintmotion/hyper-shader.js`, which replaces the HyperShader CDN script.

```html
<script src="https://cdn.jsdelivr.net/npm/gsap@3.14.2/dist/gsap.min.js"></script>
<script src="vendor/glintmotion/hyper-shader.js"></script>
<script src="vendor/glintmotion/transitions/gl-cube.js"></script>
<script>
  const tl = HyperShader.init({
    bgColor: "#000000",
    scenes: ["intro", "product"],
    transitions: [{ time: 2.4, shader: "gl-cube", duration: 0.6 }],
  });
</script>
```

The 14 built-in HyperShader shaders (`domain-warp`, `whip-pan`, `light-leak`…) keep working
with the same runtime.

## Use an effect

| Effect | GSAP plugin | What it does |
| --- | --- | --- |
| `split-headline` | SplitText | Headline rising out of masks, by word, character or line |
| `morph-icons` | MorphSVG | One shape turning into the next, with a label per shape |
| `circuit-pulse` | DrawSVG | Circuit traces drawing to a chip, then pulses of light |
| `wiggle-badge` | CustomBounce, CustomWiggle | App icon bounce, badge count-up, bell ring |
| `reaction-burst` | Physics2D | Like button throwing fountains of hearts and stars |

Each one installs to `compositions/components/<name>.html` and mounts like any HyperFrames
component, with its variables in `data-variable-values`:

```html
<div
  id="headline"
  class="clip"
  data-composition-id="split-headline"
  data-composition-src="compositions/components/split-headline.html"
  data-variable-values='{"text":"Ship it today.","split":"chars","align":"center"}'
  data-start="0"
  data-duration="3.5"
  data-track-index="0"
></div>
```

They are deterministic (fixed seeds, no measuring except SplitText's `lines` mode) and pass
`check`, the motion check and a real render: `node scripts/build-effects-gallery.mjs /tmp/fx`
writes the test project.

## Rebuild

```sh
node scripts/import-gl-transitions.mjs <gl-transitions checkout>/transitions
scripts/vendor-hyper-shader.sh <glintmotion checkout>
node scripts/build-registry.mjs
node scripts/build-gallery.mjs /tmp/gallery   # render it to check every transition
node scripts/build-effects-gallery.mjs /tmp/fx # render it to check every effect
```
